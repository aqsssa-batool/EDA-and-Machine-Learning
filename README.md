AI Usage and Impact on Students and Professionals:

📌 Project Overview

This project explores how Artificial Intelligence (AI) tools are used by students and professionals and how AI usage relates to productivity, time savings, and user satisfaction.
The project applies Exploratory Data Analysis (EDA), data cleaning, data visualization, Machine Learning, and Deep Learning to understand patterns in AI usage and predict productivity categories.
The analysis uses Python libraries to clean and transform the dataset, identify relationships between variables, visualize important findings, and compare classification models.

- Project Objectives

Analyze AI usage patterns among students and professionals.
Explore the relationship between AI usage and productivity.
Investigate how AI tools contribute to time savings and user satisfaction.
Identify the most commonly used AI tools.
Compare productivity patterns across different user groups.
Build and evaluate Machine Learning classification models.
Develop a neural network to classify productivity into High and Low categories.
